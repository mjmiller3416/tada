# Tada — Packing List Starter Templates (seed data)

> Seed data for the Phase 4 packing feature. Each template below is one category. When Tada seeds the database, create a `PackingList` with `is_template = true` for each category, its sections as `PackingSection` rows, and the items beneath each section as `PackingItem` rows (all `packed = false`). "Create from template" clones a template's sections + items into a fresh list.
>
> These are sensible starting points, not exhaustive — Maryann edits freely after cloning. Keep them lean on purpose (a helpful head start, not an overwhelming wall).
